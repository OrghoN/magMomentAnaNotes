
# nova-claude cheatsheet 

This is a cheatsheet for using the nova-claude wrapper on gpvms.
The full guide can be found [on the README for nova-claude.](https://github.com/novaexperiment/nova-claude/blob/main/docs/user-guide.md)

```bash
alias nova-claude='/cvmfs/singularity.opensciencegrid.org/novaexperiment/nova-claude:latest/usr/local/bin/nova-claude'
```

Command to generate a long lived token to interact with claude within nova-claude.
```bash
claude setup-token
```
